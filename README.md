# Ferico - DevOps Engineer & Software Developer

## Project Overview
Ferico is a personal portfolio website that showcases the skills, experience, and projects of a DevOps engineer and software developer. The website aims to present professional achievements, key skills, and a collection of notable projects through a clean and responsive design. It serves as an online CV and portfolio for potential employers and collaborators to explore.

## Installation
To set up the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ferico/portfolio.git
   ```

2. **Change into the project directory:**
   ```bash
   cd portfolio
   ```

3. **Open the `index.html` file in your preferred web browser:**
   - You can simply double-click the `index.html` file, or you can use a local server if you have one installed (like `http-server` in Node.js).

## Usage
- Navigate to the homepage (`index.html`) to view the curriculum vitae where skills, experience, education, and contact information are displayed.
- Visit the portfolio page (`portfolio.html`) to see a showcase of projects that demonstrate various competencies in DevOps and software development.

## Features
- Responsive design powered by Tailwind CSS.
- Showcases skills and experience in the DevOps and software development domains.
- Highlights notable projects with direct links to their GitHub repositories.
- Clean navigation to switch between the CV and portfolio sections.

## Dependencies
This project uses the following external libraries:

- **Tailwind CSS**: A utility-first CSS framework for styling.
- **Font Awesome**: A font and icon toolkit for adding icons to the webpage.

No package.json file was found in the provided content; hence, there are no additional dependencies listed. However, the project primarily relies on the CDN links included in the HTML files.

## Project Structure
The project has the following structure:

```
/portfolio
    ├── index.html        # Homepage showcasing the CV
    └── portfolio.html    # Portfolio page displaying projects
```

### HTML File Summaries
- **index.html**: Contains the main content for the CV, including sections for skills, experience, education, and contact information.
- **portfolio.html**: Presents a grid of project cards, each linking to GitHub repositories to view code and further details on the projects.
